Python Analysis

This folder contains the Python analysis and dashboard development for my MBA academic project, Hospital Resource Allocation and Financial Optimization.

1. Hospital Data Analysis and Machine Learning

- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Analysis of patient flow, bed occupancy, waiting time, and treatment costs
- Machine-learning techniques for operational analysis

2. Hospital Claims and Financial Dashboard

- Developed a Python dashboard using Dash and Plotly
- Displays claim approval rate, rejected claims, cash flow, and claim amount trends
- Demonstrates simulated hospital claims and financial monitoring

Tools Used

Python, Pandas, NumPy, Plotly, Dash, and machine-learning libraries.
